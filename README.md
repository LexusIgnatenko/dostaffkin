# Dostaffkin

Веб-приложение для оформления и отслеживания доставки посылок между странами и внутри стран.

## Функционал

- **Главная** — лендинг с описанием сервиса и преимуществ.
- **Оформление доставки** (`/order`):
  - Выбор маршрута через Яндекс.Карты (SuggestView + геокодирование).
  - Расчёт расстояния, срока и стоимости по тарифу.
  - Выбор размера посылки (XS–MAX) и скорости доставки (обычная/приоритетная).
  - Форма контактов и отправка заявки.
  - Отображение номера созданного отправления.
- **Отслеживание** (`/track`):
  - Поиск отправления по номеру.
  - Отображение маршрута и статусов доставки.

## Стек

- **Angular 20** (standalone components, signals, Reactive Forms)
- **TypeScript**
- **RxJS**
- **ngx-toastr** — уведомления
- **Яндекс.Карты JS API** (`ymaps`, MultiRoute, SuggestView)
- **API:** `https://testologia.ru/delivery` (`/create`, `/info`)

## Установка и запуск

```bash
npm install
npm start          # dev-сервер (ng serve)
npm run build      # production-сборка
npm test           # unit-тесты
```

Приложение откроется на `http://localhost:4200`.

## API

| Метод | Эндпоинт | Назначение |
|-------|----------|------------|
| POST  | `https://testologia.ru/delivery/create` | Создание заявки |
| GET   | `https://testologia.ru/delivery/info?id=` | Статус отправления |

## Тарифы (order.config.ts)

| Размер | Ставка (₽/км) | Мин. стоимость | Габариты |
|--------|---------------|----------------|----------|
| XS     | 9  | 149 ₽ | 17×12×9 см, до 0.5 кг |
| S      | 13 | 199 ₽ | 23×19×10 см, до 2 кг |
| M      | 20 | 249 ₽ | 33×25×15 см, до 5 кг |
| L      | 27 | 349 ₽ | 31×25×38 см, до 12 кг |
| XL     | 35 | 499 ₽ | 60×35×30 см, до 18 кг |
| MAX    | 70 | 999 ₽ | 120×120×80 см, до 200 кг |

Приоритетная доставка: ×1.15 к стоимости, срок −30%.
